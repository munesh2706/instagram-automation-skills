# instagram-automation-skills
Complete Instagram automation pipeline with 9 integrated skills
Complete end-to-end automation for Instagram content creation, scheduling, and growth optimization.

## Overview

This repository contains 9 integrated Claude skills that form a complete pipeline for:
- 🔍 Finding viral topics in your niche
- 🎣 Writing level-10 hooks (6 formulas)
- ✍️ Creating ELI5 scripts with real examples
- 🎙️ Generating AI voiceovers
- 🎬 Producing professional videos
- 📝 Writing SEO captions + strategic hashtags
- 📅 Planning 4-12 weeks of content
- 📊 Tracking engagement & analytics
- ⚙️ Optimizing channel growth
